## Bab 2: WordPress.org vs WordPress.com vs Website Builder

![Theme](assets/wp-theme.png)

### Pilihan Platform Website

**1. WordPress.org (Self-Hosted)**

Anda download software WordPress dan install di hosting sendiri.

Kelebihan:
- Full control atas website
- Semua plugin dan theme tersedia
- Bisa monetisasi tanpa batasan
- SEO friendly
- Skalabilitas unlimited
- Biaya bisa sangat murah (mulai Rp 50.000/bulan)

Kekurangan:
- Perlu setup teknis (tapi tidak sulit)
- Responsible untuk update dan security
- Butuh hosting

Best for: Bisnis serius yang ingin full control dan skalabilitas

**2. WordPress.com (Hosted)**

WordPress yang di-host oleh Automattic.

Kelebihan:
- Tidak perlu setup teknis
- Hosting included
- Security ditangani

Kekurangan:
- Terbatas di free plan (tidak bisa install plugin)
- Branding WordPress.com di website
- Mahal untuk fitur lengkap ($25-45/bln)
- Tidak bisa monetisasi sesuka hati

Best for: Personal blog sederhana

**3. Website Builder (Wix, Squarespace, Weebly)**

Drag-and-drop builder dengan hosting included.

Kelebihan:
- Sangat mudah digunakan
- Design templates bagus
- Hosting included

Kekurangan:
- Sangat terbatas customization
- Mahal ($14-40/bln)
- Tidak bisa migrate ke platform lain
- SEO terbatas
- Tidak scalable

Best for: Website sederhana tanpa rencana growth

### Rekomendasi untuk UMKM

**Pilih WordPress.org jika:**
- Ingin full control
- Plan untuk grow dan scale
- Butuh plugin dan customization
- Budget terbatas tapi ingin hasil profesional
- Serious tentang bisnis online

**Biaya WordPress.org untuk UMKM:**

| Komponen | Biaya/Tahun |
|----------|-------------|
| Domain (.com) | Rp 150.000-200.000 |
| Hosting (shared) | Rp 600.000-1.500.000 |
| Theme premium | Rp 0-1.000.000 |
| Plugin premium | Rp 0-2.000.000 |
| SSL | Rp 0 (free dari hosting) |
| Total | Rp 750.000-4.700.000/tahun |

Bandingkan dengan website builder: $200-480/tahun = Rp 3.200.000-7.700.000/tahun dengan fitur yang jauh lebih terbatas.

### WordPress Stats di 2026

- 43% dari semua website di internet pakai WordPress
- 65% market share CMS
- 500+ juta visitors ke website WordPress setiap bulan
- 50.000+ plugin tersedia

## Bab 3: Domain, Hosting, dan Setup WordPress dari Nol

![Audience](assets/wp-audience.png)

### Memilih Domain Name

**Tips Memilih Domain:**

1. **Pendek dan mudah diingat** - Maksimal 15 karakter
2. **Mencerminkan brand** - Nama bisnis atau kata kunci relevan
3. **Mudah dieja** - Hindari angka dan hyphen
4. **Ekstensi .com** - Paling dipercaya, atau .id untuk lokal
5. **Cek trademark** - Jangan melanggar merek dagang

**Registrasi Domain:**

- Niagahoster: Rp 150.000-350.000/tahun
- Domainesia: Rp 130.000-300.000/tahun
- IDWebHost: Rp 140.000-320.000/tahun
- Namecheap: $10-15/tahun

### Memilih Hosting

**Jenis Hosting:**

1. **Shared Hosting** (Rp 20.000-100.000/bulan)
   - Berbagi server dengan website lain
   - Cocok untuk blog baru dan traffic rendah
   - Recommended: Niagahoster, Domainesia, Hostinger

2. **VPS Hosting** (Rp 100.000-500.000/bulan)
   - Server virtual dedicated
   - Cocok untuk traffic menengah
   - Recommended: DigitalOcean, Vultr, Niagahoster VPS

3. **Cloud Hosting** (Rp 200.000-1.000.000/bulan)
   - Scalable dan reliable
   - Cocok untuk bisnis yang grow
   - Recommended: Cloudways, Kinsta, WP Engine

4. **Dedicated Server** (Rp 1.000.000+/bulan)
   - Server fisik dedicated
   - Cocok untuk enterprise
   - Recommended: Untuk traffic sangat tinggi

**Rekomendasi Hosting untuk UMKM:**

| Traffic | Hosting | Biaya/Bulan |
|---------|---------|-------------|
| 0-10.000 visits | Shared | Rp 30.000-75.000 |
| 10.000-50.000 visits | Cloud | Rp 150.000-300.000 |
| 50.000-200.000 visits | Managed WP | Rp 300.000-750.000 |
| 200.000+ visits | VPS/Dedicated | Rp 750.000+ |

**Hosting yang Direkomendasikan:**

1. **Niagahoster** - Best value untuk Indonesia
   - Unlimited NVMe hosting: Rp 35.000/bulan
   - Uptime 99.9%
   - Free domain dan SSL
   - Data center Singapore

2. **Domainesia** - Performance terbaik
   - WordPress hosting: Rp 55.000/bulan
   - LiteSpeed web server
   - Free daily backup
   - Support 24/7

3. **Hostinger** - Budget friendly
   - WordPress hosting: Rp 25.000/bulan
   - Good performance
   - Easy setup
   - Global data centers

### Setup WordPress Step-by-Step

**Step 1: Beli Domain dan Hosting**

1. Pilih hosting provider
2. Pilih paket hosting
3. Register domain (biasanya free tahun pertama)
4. Complete payment

**Step 2: Install WordPress**

Kebanyakan hosting punya 1-click WordPress install:

1. Login ke cPanel hosting
2. Cari "WordPress" atau "Softaculous"
3. Klik "Install"
4. Isi detail:
   - Site name: Nama bisnis Anda
   - Admin username: Pilih yang unik (bukan "admin")
   - Admin password: Kuat dan unique
   - Admin email: Email aktif Anda
5. Klik "Install"
6. Tunggu 1-2 menit
7. Akses website di domain Anda

**Step 3: Basic Configuration**

1. Login ke WordPress admin: yourdomain.com/wp-admin
2. Settings > General:
   - Site Title: Nama bisnis
   - Tagline: Deskripsi singkat
   - WordPress Address dan Site Address: Pastikan sama
3. Settings > Permalinks:
   - Pilih "Post name" (paling SEO friendly)
4. Settings > Reading:
   - Homepage: Pilih static page atau latest posts
5. Settings > Discussion:
   - Configure comment settings

**Step 4: Security Setup**

1. Install SSL (biasanya free dari hosting)
2. Install security plugin: Wordfence atau Sucuri
3. Change login URL (WPS Hide Login)
4. Setup 2FA (Two-Factor Authentication)
5. Regular backup setup

**Step 5: Essential Pages**

Buat halaman dasar:
- Home
- About Us
- Services/Products
- Blog
- Contact
- Privacy Policy
- Terms of Service

## Bab 6: Strategi Konten Blog yang Menarik Traffic

![SEO](assets/wp-seo.png)

### Content Strategy Framework

**1. Define Target Audience**

Siapa yang ingin Anda tarik?
- Demographics: umur, gender, lokasi, pendapatan
- Psychographics: minat, masalah, goals
- Behavior: bagaimana mereka search, apa yang mereka baca

**2. Content Pillars**

Pilih 3-5 topik utama yang menjadi expertise bisnis Anda:

Contoh untuk toko sepatu running:
- Pillar 1: Running tips dan training
- Pillar 2: Shoe reviews dan comparisons
- Pillar 3: Running gear dan equipment
- Pillar 4: Health dan injury prevention
- Pillar 5: Race events dan community

**3. Content Types**

Variasi format konten:
- How-to guides
- Listicles (10 tips, 5 cara, dll)
- Case studies
- Product reviews
- Comparison posts (A vs B)
- Industry news dan trends
- Expert interviews
- Data-driven posts

**4. Keyword Research untuk Blog**

Gunakan tools:
- Google Keyword Planner (free)
- Ubersuggest (freemium)
- Ahrefs (paid)
- SEMrush (paid)
- AnswerThePublic (free)

Cari keyword dengan:
- Volume pencarian cukup (100-1000/bulan)
- Kompetisi rendah sampai medium
- Relevan dengan bisnis
- Intent yang jelas

**5. Content Calendar**

Plan konten 1-3 bulan ke depan:

| Minggu | Topik | Keyword Target | Type | Status |
|--------|-------|----------------|------|--------|
| 1 | Cara memilih sepatu running | sepatu running terbaik | How-to | Draft |
| 2 | Review Nike Pegasus 40 | review nike pegasus | Review | Idea |
| 3 | 10 tips lari untuk pemula | tips lari pemula | Listicle | Published |
| 4 | Asics vs Nike running | asics vs nike | Comparison | Idea |

### Menulis Artikel Blog yang Efektif

**Struktur Artikel:**

1. **Headline** (H1)
   - Include keyword utama
   - Menarik perhatian
   - 50-60 karakter
   - Gunakan angka jika memungkinkan

2. **Introduction** (100-200 kata)
   - Hook pembaca
   - State masalah/topik
   - Preview apa yang akan dipelajari
   - Include keyword di 100 kata pertama

3. **Body** (500-2000 kata)
   - Gunakan H2 untuk main sections
   - Gunakan H3 untuk sub-sections
   - Short paragraphs (2-3 sentences)
   - Bullet points dan numbered lists
   - Images dan visuals
   - Internal dan external links

4. **Conclusion** (100-200 kata)
   - Summary key points
   - CTA (call to action)
   - Related articles

**Writing Tips:**

- Tulis untuk manusia, bukan search engine
- Gunakan bahasa conversational
- Break up text dengan visuals
- Include data dan statistics
- Share personal experience
- Edit ruthlessly (hapus yang tidak perlu)
- Proofread sebelum publish

### Content Optimization

**On-Page SEO:**

- Keyword di title (H1)
- Keyword di URL
- Keyword di first 100 words
- Keyword di H2 headings (natural)
- Keyword density 1-2%
- Meta title optimized
- Meta description compelling
- Image alt text dengan keyword
- Internal links ke related posts
- External links ke authoritative sources

**Readability:**

- Flesch Reading Ease score 60+
- Short sentences (max 20 words)
- Short paragraphs (max 3 sentences)
- Transition words
- Subheadings setiap 300 kata
- Active voice

### Content Repurposing

1 artikel blog bisa jadi:
- 5-10 social media posts
- 1 email newsletter
- 1 video YouTube
- 1 podcast episode
- 1 infographic
- 5-10 Twitter threads
- 1 LinkedIn article

Maximize value dari setiap konten yang dibuat.

## Bab 7: SEO On-Page dan Technical SEO untuk Blog

![Analytics](assets/wp-analytics.png)

### SEO On-Page Checklist

**Untuk Setiap Artikel:**

- [ ] Keyword utama di title tag (H1)
- [ ] Keyword di URL slug
- [ ] Keyword di first 100 words
- [ ] Keyword di minimal 1 H2
- [ ] Keyword density 1-2%
- [ ] Meta title 50-60 characters dengan keyword
- [ ] Meta description 150-160 characters, compelling
- [ ] Image alt text dengan keyword (natural)
- [ ] Internal links 3-5 ke related posts
- [ ] External links 2-3 ke authoritative sources
- [ ] Short paragraphs (2-3 sentences)
- [ ] Bullet points dan numbered lists
- [ ] Images dan visuals
- [ ] Table of contents untuk long posts
- [ ] Schema markup (Article, FAQ, HowTo)

### Technical SEO

**1. Site Speed**

Google PageSpeed Insights target: 90+ score

Optimizations:
- Compress images (WebP format)
- Enable caching
- Minify CSS dan JavaScript
- Use CDN
- Choose fast hosting
- Limit plugins
- Lazy load images

**2. Mobile Optimization**

- Responsive design
- Touch-friendly elements
- Fast mobile loading
- Readable text without zoom
- No horizontal scrolling

**3. SSL/HTTPS**

- Install SSL certificate (free dari hosting)
- Force HTTPS
- Update internal links ke HTTPS

**4. XML Sitemap**

- Generate sitemap (Yoast/Rank Math auto-generate)
- Submit ke Google Search Console
- Update otomatis saat publish new content

**5. Robots.txt**

- Allow search engines to crawl
- Block admin dan private pages
- Include sitemap location

**6. Structured Data (Schema)**

Types untuk blog:
- Article schema
- Breadcrumb schema
- FAQ schema
- HowTo schema
- Review schema

**7. Core Web Vitals**

- LCP (Largest Contentful Paint): < 2.5s
- FID (First Input Delay): < 100ms
- CLS (Cumulative Layout Shift): < 0.1

### Link Building Strategy

**Internal Linking:**

- Link ke related posts
- Use descriptive anchor text
- Create content hubs (pillar pages)
- Update old posts dengan new links

**External Link Building:**

- Guest posting di blog lain
- Broken link building
- Resource page link building
- HARO (Help A Reporter Out)
- Create linkable assets (infographics, research)

### Local SEO untuk Blog

Jika bisnis Anda lokal:

- Optimize untuk "[keyword] + [kota]"
- Include NAP (Name, Address, Phone) di website
- Create location-specific content
- Get reviews di Google My Business
- Build local citations

## Bab 8: Monetisasi Blog dan Website Bisnis

![ROI](assets/wp-roi.png)

### Cara Monetisasi Blog

**1. Menjual Produk/Jasa Sendiri**

Paling profitable karena margin 100%.

Contoh:
- Toko online menjual produk fisik
- Jasa konsultasi atau coaching
- Digital products (ebook, course, templates)
- Membership site

**2. Affiliate Marketing**

Komisi dari merekomendasikan produk orang lain.

Program affiliate populer:
- Shopee Affiliate (komisi 5-10%)
- Tokopedia Affiliate (komisi 3-8%)
- Amazon Associates (komisi 4-10%)
- Niagahoster Affiliate (komisi Rp 60.000-600.000/sale)
- Traveloka Affiliate (komisi 3-5%)

**3. Display Ads**

Iklan dari ad network.

Networks:
- Google AdSense (paling populer, mudah)
- Ezoic (AI-powered, revenue lebih tinggi)
- Media.net (Bing/Yahoo network)
- AdThrive/AdMediate (require 100K+ pageviews)

Revenue:
- AdSense: $1-5 per 1000 pageviews
- Ezoic: $5-15 per 1000 pageviews
- AdThrive: $15-30 per 1000 pageviews

**4. Sponsored Posts**

Dibayar untuk menulis tentang produk/layanan brand.

Rate:
- Blog kecil (1K-5K traffic): Rp 500.000-2.000.000/post
- Blog medium (5K-50K traffic): Rp 2.000.000-10.000.000/post
- Blog besar (50K+ traffic): Rp 10.000.000-50.000.000/post

**5. Digital Products**

Jual produk digital yang Anda buat:
- Ebooks: Rp 50.000-500.000
- Online courses: Rp 100.000-5.000.000
- Templates: Rp 50.000-500.000
- Software/tools: Rp 100.000-1.000.000/bulan

**6. Membership/Subscription**

Konten eksklusif untuk member berbayar:
- Rp 50.000-500.000/bulan
- Exclusive content
- Community access
- Early access
- Discounts

### Strategi Monetisasi untuk Blog Baru

**Phase 1: 0-1000 visitors/bulan (Bulan 1-6)**
- Focus: Build content dan traffic
- Monetization: Affiliate links di konten
- Revenue expectation: Rp 0-500.000/bulan

**Phase 2: 1000-10.000 visitors/bulan (Bulan 6-12)**
- Focus: Grow traffic dan build email list
- Monetization: Affiliate + display ads (AdSense)
- Revenue expectation: Rp 500.000-5.000.000/bulan

**Phase 3: 10.000-50.000 visitors/bulan (Bulan 12-24)**
- Focus: Optimize monetization dan launch products
- Monetization: Affiliate + ads + own products
- Revenue expectation: Rp 5.000.000-30.000.000/bulan

**Phase 4: 50.000+ visitors/bulan (Bulan 24+)**
- Focus: Scale dan diversify
- Monetization: All channels + sponsored posts
- Revenue expectation: Rp 30.000.000+/bulan

### Studi Kasus 1: Blog Resep Masakan

**Profil:**
- Nama: "Dapur Nusantara"

### Optimasi Berbasis Data

**1. Improve Underperforming Content**

- High impressions tapi low clicks → improve title dan meta description
- High traffic tapi low conversion → improve CTA dan content
- High bounce rate → improve content quality dan UX

**2. Double Down on What Works**

Identify posts dengan:
- High traffic dan high conversion → buat lebih banyak konten serupa
- High engagement → update dan expand
- Good rankings → optimize lebih lanjut

**3. Content Refresh**

Update old posts:
- Add new information
- Improve SEO
- Update images
- Fix broken links
- Republish dengan tanggal baru

- Human editor untuk quality
- 5-10x faster production
- Cost: Rp 10.000-50.000/artikel

**Option 3: User-Generated Content**

- Guest posts
- Expert interviews
- Community contributions
- Free content untuk exposure

### Multi-Site Strategy

**Kapan Perlu Multi-Site:**

- Different niches/audiences
- Different languages
- Different business lines
- Scale beyond single site capacity

**Multi-Site Setup:**

1. **WordPress Multisite Network**
   - Satu WordPress installation
   - Multiple sites dalam satu network
   - Shared plugins dan themes
   - Centralized management

   - Each site independent
   - More flexibility
   - More maintenance
   - Better isolation
